# 发布说明

## 发给别人用哪个文件？

把文件夹 `发布` 里的：

**`听小说安装包_vX.Y.Z.exe`**

发给对方即可（文件名中的版本号随打包时指定变化）。

## 自己重新打包安装包

1. 先确保 `听小说应用\听小说.exe` 是最新版（可用 `novel_listener\build_exe.bat` 重新生成）
2. 在项目根目录打包，并自定义版本号：

```bat
build_installer.bat 1.2.0
```

或双击 `build_installer.bat`，按提示输入版本号（直接回车则使用 `VERSION` 文件中的默认值）。

3. 生成结果：`发布\听小说安装包_v1.2.0.exe`

## 版本号说明

- 推荐格式：`主版本.次版本.修订号`，例如 `1.0.0`、`1.2.3`
- 也可使用四段：`1.2.3.4`
- 成功打包后会写入根目录 `VERSION`，下次默认沿用

## 说明

- 安装程序使用 Inno Setup，默认装到「程序文件」或用户自选目录
- 可选创建桌面快捷方式
- 卸载不会删除听书进度（`%USERPROFILE%\.novel_listener`）
