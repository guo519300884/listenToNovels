# 发布说明

## 发给别人用哪个文件？

把文件夹 `发布` 里的：

**`听小说安装包_v1.0.0.exe`**

发给对方即可。对方双击运行 → 选安装目录 → 完成，即可从开始菜单/桌面启动。

## 自己重新打包安装包

1. 先确保 `听小说应用\听小说.exe` 是最新版（可用 `novel_listener\build_exe.bat` 重新生成）
2. 双击项目根目录的 `build_installer.bat`
3. 生成结果在 `发布\` 目录

## 说明

- 安装程序使用 Inno Setup，默认装到「程序文件」或用户自选目录
- 可选创建桌面快捷方式
- 卸载不会删除听书进度（`%USERPROFILE%\.novel_listener`）
