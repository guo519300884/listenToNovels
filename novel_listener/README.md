# 听小说（真人语音版）

使用微软神经网络真人语音朗读小说，听感接近车载导航播报。

## 支持格式

- `.txt` / `.md` 文本
- `.pdf` PDF（需含可选中文字；扫描版图片 PDF 无法朗读）
- `.doc` / `.docx` Word（`.doc` 建议本机已安装 Microsoft Word）
- `.epub` 电子书
- `.rtf` / `.html` 富文本与网页

## 功能

- 真人神经网络中文语音
- 朗读速度：0.5x～5.0x
- 正文搜索定位、章节目录
- 自动分章、进度记忆

## 注意

播放时需要联网（用于生成真人语音）。

双击 `听小说.exe` 打开小说文件即可。
