# 听小说使用说明

## 怎么启动（推荐）

1. **有 Python**：双击 `启动听小说.bat`（始终用仓库最新源码，最高 **10 倍速**）
2. **只要 exe**：双击本目录 `重新打包exe.bat` 生成最新 `听小说.exe`，再双击 exe

> 旧版绿色 `听小说.exe` 若未重新打包，倍速仍可能停在约 3～5 倍。请用上面任一方式更新。

## 支持格式
- 小说：txt / pdf / doc / docx / epub / rtf / html / md
- 压缩包：zip / 7z / tar / tar.gz / gz（可直接导入，自动解压出其中的小说）
- RAR：若本机已配置 UnRAR 可尝试；建议先转为 zip / 7z

## 体积上限
- 单个压缩包：约 1GB
- 解压合计：约 4GB
- 包内单文件：约 800MB
- 文件夹扫描：最多约 3000 个文件

## 书架（多本收听）
1. 左侧点「导入小说」可一次选择多本或压缩包，或「导入文件夹」批量添加
2. 切到「书架」点选要听的书；切到「目录」跳转章节
3. 书架里点 × 可移除（不会删除磁盘文件）
4. 每本书的进度会分别记住，下次打开自动续听

## 播放
- 底部选择「讲书音色」，调速度后点播放（预设最高 **10x**）
- 单击正文可从该位置开始听；拖动进度条可跳转
- 朗读时正文会高亮并自动跟随滚动
- `3x` 以上由本地加速补齐（音调会升高，属正常现象）

## 注意
- PDF 需为可选中文字的文档；纯扫描图片 PDF 读不出字
- 旧版 .doc 建议电脑已安装 Microsoft Word，或先另存为 .docx
- 朗读需联网（真人神经网络语音）
- 从压缩包导入的文件会解压到 `%USERPROFILE%\.novel_listener\imports\`
