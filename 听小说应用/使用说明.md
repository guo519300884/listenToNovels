# 听小说使用说明（绿色版 · 最高 10 倍速）

## 启动

双击 **听小说.exe** 即可。

- 首次启动会自动解压 `runtime_pack.zip`（约半分钟），之后秒开
- 本版最高 **10.0x**；`3.0x` 以上由本地加速补齐
- **调节速度后立即应用到当前朗读**（无需等下一句）

请保持同目录含有：`听小说.exe`、`runtime_pack.zip`、`app\app.py`

## 支持格式

- 小说：txt / pdf / doc / docx / epub / rtf / html / md
- 压缩包：zip / 7z / tar / tar.gz / gz（可直接导入，自动解压）

## 书架

1. 「导入小说」可多选或导入压缩包，「导入文件夹」批量添加
2. 「书架」选书，「目录」跳章节
3. 书架里点 × 可移除（不删磁盘文件）
4. 每本书进度分别记住

## 播放

- 底部选音色、调速度后点播放
- 单击正文可从该处开听；可拖进度条
- 朗读时正文高亮跟随

## 注意

- PDF 需为可选中文字；扫描版图片 PDF 读不出字
- 旧 `.doc` 建议已装 Word，或另存为 `.docx`
- 朗读需联网（真人神经网络语音）
- 数据目录：`%USERPROFILE%\.novel_listener\`
