# 听小说使用说明

## 支持格式
txt / pdf / doc / docx / epub / rtf / html / md

## 书架（多本收听）
1. 左侧点「导入小说」可一次选择多本，或「导入文件夹」批量添加
2. 切到「书架」点选要听的书；切到「目录」跳转章节
3. 书架里点 × 可移除（不会删除磁盘文件）
4. 每本书的进度会分别记住，下次打开自动续听

## 播放
- 底部选择「讲书音色」，调速度后点播放
- 单击正文可从该位置开始听；拖动进度条可跳转
- 朗读时正文会高亮并自动跟随滚动

## 注意
- PDF 需是可选中文字的文档；纯扫描图片 PDF 读不出字
- 旧版 .doc 建议电脑已安装 Microsoft Word，或先另存为 .docx
- 朗读需联网（真人神经网络语音）

双击「听小说.exe」即可使用。
